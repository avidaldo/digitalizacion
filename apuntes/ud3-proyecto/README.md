# UD3 — El proyecto

Tercer trimestre. No hay contenido nuevo ni examen: es el trimestre en el que se trabaja, se
defiende y se evalúa el proyecto de transformación digital de una empresa elegida por cada alumno.
Pesa el 40 % de la nota final.

| Apunte | Qué es |
|---|---|
| [01 Metodología del proyecto](01-metodologia-del-proyecto.md) | El método: la cadena de razonamiento de objetivos a tecnología, personas y documentación. Incluye el uso responsable de IA y la plantilla de ADR |
| [02 Ejemplo trabajado](02-ejemplo-trabajado.md) | El método aplicado, abreviado, a un taller mecánico inventado: qué aspecto tienen las decisiones cuando están justificadas, y las preguntas que aguantarían en la exposición |
